# Montreal fire analysis

This repository contains the data and code used by [Science for the People Montreal](https://sftp-canada.org/) to analyze data on Montreal fires.

## Data

The data comes from the Government of Canada's [website about the interventions by the Montreal Fire Safety Service](https://open.canada.ca/data/en/dataset/2fc8a2b9-1556-410e-a118-c46e97e9f19e) (SIM), that is the Montreal firefighters.

There are four databases, for four different periods:

- [SIM interventions - current (last 2 years)](https://open.canada.ca/data/en/dataset/2fc8a2b9-1556-410e-a118-c46e97e9f19e/resource/2f7f2ff4-fbba-4e49-81ec-9f69fcae51f3)
- [SIM interventions - 2020 to 2024](https://open.canada.ca/data/en/dataset/2fc8a2b9-1556-410e-a118-c46e97e9f19e/resource/7a4f510f-0634-4ea2-bde2-2b985c42a621)
- [SIM interventions - 2015 to 2022](https://open.canada.ca/data/en/dataset/2fc8a2b9-1556-410e-a118-c46e97e9f19e/resource/f856fa38-138f-4ba8-9fd9-4f4f0fb72889)
- [SIM interventions - 2005 to 2014](https://open.canada.ca/data/en/dataset/2fc8a2b9-1556-410e-a118-c46e97e9f19e/resource/0f73cd89-1978-4a6c-9d0f-9cf22dae120d)
