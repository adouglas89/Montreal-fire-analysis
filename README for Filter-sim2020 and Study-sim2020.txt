Filter-sim2020.py and Study-sim2020.py are two python scripts that can be used in tandem to analyse and build plots for more recent SIM .csv files (they are currently configured to run on the file “donneesouvertes-interventions-sim2020.csv” but should safely work on “donneesouvertes-interventions-sim_2015_2022.csv” and “donneesouvertes-interventions-sim.csv” as well. The older “donneesouvertes-interventions-sim-2005-2014.csv” will require some minor adaptations to account for changes in the SIM’s coding/reporting between these years)

TO USE:
- Place both python scripts together with the .csv files you want to work with in your working directory
- In the file Filter-sim2020.py, set CSV_PATH to the name of the .csv file that you wish to analyse
- Run Filter-sim2020.py. This script will prompt you to enter a start date (obligatory), and end date (obligatory), a list of incident types (optional), a list of group descriptions (optional) and a list of arrondissements (optional). It will then run through the .csv file and produce a new .csv file called “filtered_interventions.csv” in your working directory which contains only those entries which lie between the entered start and end dates, and has INCIDENT_TYPE_DESC in the prompted list of incident types, DESCRIPTION_GROUPE in the prompted list of group descriptions and NOM_ARROND in the prompted list of arrondissements. If you leave any of the optional prompts empty, then you will simply not filter by this variable.

- After running Filter-sim2020.py, you can simply directly run Study-sim2020.py, and it will produce several plots and a short summary allowing the comparison of fire incidents in the data table “filtered_interventions.csv” over time and by neighbourhood, according to either a strict or a broad definition of “fire incident” (see the comments of Study-sim2020.py for more details on this)
